# Webview Side — File Map

All files share the **same `window` global scope** — loaded as ordered `<script>` tags. A function declared in an earlier file is available to all later files.

| Load Order | File | Purpose | Key Globals Declared |
| - | - | - | - |
| 1 | `media/state.js` | All mutable UI state + app data received from extension. `state.workspaceFolders` holds `Array<{ name, fsPath }>` received from the extension — populated only in multi-root workspaces. `aiState.modelsLoading` is `true` while the model list is being fetched from the API; set to `false` when the fetch completes or when no API key is saved for the selected provider. | `vscode`, `RUNBOX_EMPTY_VALUE`, `uiState`, `aiState`, `state`, `variableInputState`, `runConfirmState`, `aiExplainState` |
| 2 | `media/icons.js` | All inline SVG icon strings. Includes `icons.folder` (used by the workspace selector bar in multi-root mode). | `icons` |
| 3 | `media/utils.js` | Pure utilities + custom select component system + scope draft helpers + actions cell renderer + row selection + notice system + template syntax highlighting + category/group/command helpers + favorites helpers + persist helpers + time helpers | `escapeHtml`, `escapeAttr`, `escapeRegExp`, `timeAgo`, `formatDateTime`, `generateEntityId`, `collectVariables`, `getEnabledAutoVariableNames`, `getMissingVariables`, `resolveCommandTemplate`, `resolveGroupTitle`, `getCommandLocalDraft`, `getCommandGlobalDraft`, `getCommandSessionDraft`, `getCommandDraft`, `getCommandRemember`, `buildCommandVariablesPayload`, `updateScopeIndicatorDots`, `setSelectedCategory`, `getSelectedCategory`, `getSelectedCategoryGroups`, `getVisibleCommands`, `getEditingCommand`, `highlightTemplateHtml`, `highlightResolvedHtml`, `autoResizeTextarea`, `updateTemplateHighlight`, `showNotice`, `showError`, `paintNotice`, `selectCommandRow`, `scrollToAndHighlight`, `bindCmdTitleLinks`, `isInFavorites`, `getFavoriteScope`, `persistFavorites`, `persistDataThenRender`, `persistCommandVariables`, `renderActionsCell`, `renderCustomSelect`, `bindCustomSelect` |
| 5 | `media/markdown-parser.js` | Lightweight Markdown → HTML converter. Supports: `##`/`###` headings, `**bold**`, `*italic*`, `` `inline code` ``, fenced code blocks, `- lists`, `1. lists`, `> blockquote`, and `\| tables \|`. No external dependencies. | `renderMarkdown`, `inlineMarkdown` |
| 6 | `media/modals/run-confirm.js` | Run Confirmation modal + Variable Input modal + Delete Confirm modal. | `renderToggleSwitch3`, `renderShellSelector`, `renderRunConfirmModal`, `renderVariableInputModal`, `renderDeleteConfirmModal` |
| 7 | `media/modals/command-form.js` | Single source of truth for the Command form UI, used by both **Add** and **Edit** modes. Rendered as a full tab. All field and variable-scope state lives in `commandFormBuffer`; global state is only written on submit. | `COMMAND_FORM_CTX`, `commandFormBuffer`, `getUserVariableNames`, `renderCommandFormVariables`, `renderCommandForm`, `transferVariableData`, `pruneOrphanVariables`, `flushScopeDataToState`, `closeCommandForm`, `bindCommandFormVariableInputs`, `bindCommandFormScopeToggles`, `bindCommandFormEnumButtons`, `bindCommandFormTemplateInput`, `validateCommandForm`, `submitAddCommand`, `submitEditCommand`, `bindCommandFormEvents` |
| 8 | `media/modals/ai-settings.js` | AI Settings modal (provider selector + cascading model selector + API key) + localStorage model cache helpers + settings bind events | `renderAiSettingsModal`, `renderAiProviderSetupModal`, `bindAiSettingsEvents`, `getAiModelLabel`, `buildModelOptions`, `resolveSettingsModelId`, `getCachedModels`, `setModelsCache`, `clearModelsCache`, `getModelsCacheFetchedAt`, `formatTimeAgo` |
| 9 | `media/modals/ai-generate.js` | AI Generate prompt, loading overlay, results modal, and generate/results bind events | `renderAiPromptModal`, `renderAiLoadingOverlay`, `renderAiResultsModal`, `bindAiGenerateEvents` |
| 10 | `media/modals/ai-explain.js` | AI Explain modal — opens immediately in loading state when `.btn-explain` is clicked; displays structured Markdown explanation of a CLI command returned by `explainWithAI`. Manages `aiExplainState`. | `openAiExplainModal`, `closeAiExplainModal`, `handleAiExplainResult` |
| 11 | `media/modals/enum-manager.js` | Enum Manager modal - manages enum variable options (title/value/description). Opened from the command form and writes through `commandFormBuffer.variableMeta` | `renderEnumManagerModal`, `bindEnumManagerEvents` |
| 12 | `media/modals/ai-check-status.js` | AI Check Status modal — shared by "Check Connection" and "Check Rate Limits" buttons in AI Settings. Injected directly into `document.body` (same pattern as `ai-explain.js`), independent of the main `render()` cycle. Shows a loading spinner, then either the connection result, the rate limit values (generic label/value rows built from whatever keys the provider returned), or — for providers with `hasApiRateLimits: false` — a message plus a clickable link to the provider's own rate-limit page. Manages `aiCheckStatusState`. | `openAiCheckConnectionModal`, `openAiCheckRateLimitsModal`, `closeAiCheckStatusModal`, `handleAiCheckConnectionResult`, `handleAiCheckRateLimitsResult` |
| 13 | `media/tabs/recent.js` | "Recent" tab | `renderRecentCommandsTab`, `bindRecentTabEvents` |
| 14 | `media/tabs/commands.js` | "Commands" tab (largest — filtering, table, sort, all action buttons + modals binding) | `renderCommandsTab`, `renderCommandsTable`, `bindCommandsTabEvents`, `bindCommandActionButtons`, `performCommandAction`, `dispatchCommandAction` |
| 15 | `media/tabs/favorites.js` | "Favorites" tab | `renderFavoritesTab`, `bindFavoritesTabEvents` |
| 16 | `media/tabs/variables.js` | "Variables" tab | `renderVariablesTab`, `bindVariablesTabEvents` |
| 17 | `media/tabs/categories.js` | "Categories & Groups" tab (also hosts the AI Create entry point) | `renderCategoriesTab`, `renderCategoriesModal`, `bindCategoriesTabEvents`, `executeManageModalConfirm` |
| 18 | `media/render.js` | Master `render()` orchestrator + state hydration + event binding entry points. `renderWorkspaceLabel()` renders the workspace label bar below the header: a plain text label in single-root mode; a `renderCustomSelect` dropdown (wrapperId `workspace-folder-select`) in multi-root mode, bound in `bindTopActions()` to post `setActiveWorkspaceFolder`. | `render`, `hydrateState`, `ensureSelectionDefaults`, `renderWorkspaceLabel`, `bindEvents`, `bindTopActions`, `bindTabs`, `bindModalDismiss`, `bindRowSelectionEvents` |
| 19 | `media/messages.js` | Single `window.addEventListener("message", ...)` block — all extension messages are handled inline with `if (message.type === ...)` branches. No named handler functions are exported. | _(none — all logic is inline inside the listener)_ |
| 20 | `media/main.js` | Loaded last. Contains: a `contextmenu` event listener (suppresses context menu unless text is selected), the tooltip IIFE (VS Code-style hover tooltips via event delegation), and a single `vscode.postMessage({ type: "ready" })` call to signal the extension. No named post functions — all `postMessage` calls are inlined at their call sites throughout tabs and modals. | _(none)_ |
